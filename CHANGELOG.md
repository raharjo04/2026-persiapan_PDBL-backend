# Changelog
Semua perubahan signifikan pada proyek ini akan dicatat dalam file ini.

## [1.0.0] - 2026-02-13
### Ditambahkan
- Inisialisasi proyek backend menggunakan ASP.NET Core sesuai standar industri.
- Implementasi modul CRUD lengkap untuk fitur Peminjaman Ruangan (Tambah, Lihat, Detail, Ubah, Hapus).
- Fitur Pengelolaan Status Peminjaman (Pending, Disetujui, Ditolak).
- Implementasi Soft Deletes untuk keamanan data transaksi.
- Setup dokumentasi proyek menggunakan README.md dan CHANGELOG.md.
- Konfigurasi manajemen tugas melalui GitHub Project Board.
